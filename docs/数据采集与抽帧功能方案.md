# 数据采集（录像 + 智能抽帧）功能方案

> 目标：**连接相机 → 录制一段作业视频 → 按自定义参数抽帧导出图片**，用于 YOLO 标注流水线的样本采集。
> 核心价值：**一次录制，多次抽帧**。作业视频留存后可在事后反复用不同参数重抽，不必重复现场作业。

## 二、总体流程（三级流水线）

```
① 录制       相机帧 → 有界队列 → 后台任务 → ffmpeg stdin → session.mp4
                      （取帧与写盘解耦，避免拖慢预览 / 丢帧）

② 粗抽       session.mp4 → ffmpeg(-vf fps=/select=scene, scale) → 临时候选帧
                      （解码/缩放/格式/画质交给 ffmpeg，稳定且不丢 format）

③ 精筛 + 输出  候选帧 → OpenCvSharp 打分（清晰度/亮度/对比度/pHash 去重）
                      → 保留/剔除 → 按模板重命名 → meta.json + frames.csv
```

> 为什么分级：**ffmpeg 负责"重活"（解码、选帧、缩放、编码），C# 只负责"判断"（image quality scoring）**。避免用 C# 逐帧解码整个视频带来的性能与内存问题，也避免 ffmpeg 无法表达复杂语义（去模糊、全局去重）的短板。

## 三、参数设计（本次新增，全部可持久化）

### 3.1 录制参数（Record）

| # | 参数 | 默认值 | 说明 |
|---|---|---|---|
| R1 | `SessionName` | `session_yyyyMMdd_HHmmss` | 会话名，决定输出目录名 |
| R2 | `OutputRoot` | `dataset/` | 采集根目录（相对程序基目录） |
| R3 | `VideoCodec` | `H.264 (libx264)` | 可选 H.264 / H.265 / MJPEG（无损但大） |
| R4 | `Crf` | `18` | 画质；12 近无损 / 18 推荐 / 23 更小。MJPEG 时忽略 |
| R5 | `Preset` | `veryfast` | ultrafast / veryfast / medium；越慢体积越小、CPU 越高 |
| R6 | `RecordFps` | `跟随相机`（上限可选 15/20/25/30） | 限制写入帧率，防止视频过大 |
| R7 | `MaxDurationSec` | `0`（不限） | 安全上限，超时自动停录 |
| R8 | `MaxFileSizeMB` | `0`（不限） | 超限自动停录，防磁盘写满 |
| R9 | `QueueCapacity` | `60` 帧 | 有界队列；写盘慢时**丢最新帧**而非堆积内存 |
| R10 | `TriggerMode` | `手动开始/停止` | 预留：Modbus X 口硬件触发（二期） |
| R11 | `KeepRawVideo` | `true` | 抽帧后是否保留源视频（便于日后重抽） |

**像素格式兼容**：相机可能输出 Mono8（1 通道）或 BGR24（3 通道），按 `Channels/IsColor` 自动拼 ffmpeg 的 `-pix_fmt`（`gray` / `bgr24`）。

### 3.2 抽帧 — 采样策略（Sampling，五选一或叠加）

| # | 参数 | 默认 | 说明 |
|---|---|---|---|
| S1 | `Strategy` | `TargetCount` | ① `IntervalFrames` 每 N 帧 ② `IntervalMs` 每 N 毫秒 ③ `TargetFps` 目标帧率 ④ **`TargetCount` 均匀抽 N 张** ⑤ `SceneChange` 场景切换触发 |
| S2 | `IntervalFrames` | `10` | 策略①用。每 10 帧取 1 张 |
| S3 | `IntervalMs` | `500` | 策略②用。每 0.5 秒取 1 张 |
| S4 | `TargetFps` | `2` | 策略③用。每秒抽 2 张 |
| S5 | `TargetCount` | `200` | 策略④用。**强烈推荐**：告诉系统"我要 200 张"，自动按总时长均匀采样 |
| S6 | `SceneThreshold` | `0.01` | 策略⑤用。画面变化量 > 阈值才取。**实测极其敏感（见下方实测表），默认 0.01** |
| S7 | `StartTimeSec` / `EndTimeSec` | `0` / `0`(到尾) | 只抽视频某一段（跳过开头准备动作） |
| S8 | `FrameStepOverridesFlags` | `false` | 是否允许叠加：先按 S2/S3/S5 粗抽，再用 S6 场景二次过滤 |

> **S6 实测标定（务必先看数据再调）**
> | 视频 | 0.005 | 0.01 | 0.02 | 0.05 | 0.1 |
> |---|---|---|---|---|---|
> | 静态机位航拍 1280×720@30fps / 66s | — | — | 33 张 | 2 张 | 0 张 |
> | 手持拍摄 4K@60fps / 前 30s（1799 帧） | 209 帧 | 57 帧 | 5 帧 | 1 帧 | 0 张 |
>
> 结论：该视频最大场景评分仅 0.054（手眼看"变化大"≠ ffmpeg 评分高），**高帧率视频相邻帧差异天然更小**，阈值要往下压。默认 0.01 ≈ 2 帧/秒。

### 3.3 抽帧 — 图像质量过滤（Quality，★保障数据集可用性的关键）

| # | 参数 | 默认 | 判定规则 |
|---|---|---|---|
| Q1 | `EnableQualityFilter` | `true` | 总开关 |
| Q2 | `MinSharpness` | `20` | 拉普拉斯方差；低于此值判定为**运动模糊/失焦**，剔除（**取值见下方标定**） |
| Q3 | `MinBrightness` | `30` | 灰度均值下限，剔除过暗帧（0-255） |
| Q4 | `MaxBrightness` | `225` | 灰度均值上限，剔除过曝帧 |
| Q5 | `MinContrast` | `15` | 灰度标准差下限，剔除纯色/无纹理帧 |
| Q6 | `BrightnessRoiOnly` | `false` | 是否只在 ROI 内统计亮度（配合产品区域） |

### 3.4 抽帧 — 去重（Dedup，★避免标注工时的最大浪费）

| # | 参数 | 默认 | 说明 |
|---|---|---|---|
| D1 | `EnableDedup` | `true` | 总开关 |
| D2 | `Method` | `pHash` | `pHash`(感知哈希) / `dHash` / `Histogram`(直方图相关性) |
| D3 | `HammingThreshold` | `8` | pHash/dHash 汉明距离；≤ 阈值视为重复（建议 5~10） |
| D4 | `HistogramThreshold` | `0.985` | 直方图相似度；≥ 阈值视为重复 |
| D5 | `Scope` | `PreviousKept` | `PreviousKept`(只与上一张保留帧比，快) / `AllKept`(与全部已留帧比，彻底但慢) |
| D6 | `CrossSessionDedup` | `false` | 跨会话全局去重（与 `dataset/_hashlib.json` 比对），避免不同批次重复样本 |
| D7 | `MotionMinDelta` | `0` | 与上一保留帧的最小像素差异；过小直接跳过（静止画面） |

### 3.5 抽帧 — 输出与后处理（Output）

| # | 参数 | 默认 | 说明 |
|---|---|---|---|
| O1 | `OutputFormat` | `jpg` | jpg / png / bmp；标注推荐 jpg（体积小） |
| O2 | `JpegQuality` | `95` | 1-100 |
| O3 | `ResizeMode` | `LimitLongEdge` | `None` / `LimitLongEdge` / `FixedSize` / `Percent` |
| O4 | `MaxLongEdge` | `1920` | O3=LimitLongEdge 时生效，保持宽高比 |
| O5 | `CropRoi` | `空`（全图） | 裁剪区域 x,y,w,h；**UI 可画框选中间输浜** |
| O6 | `Grayscale` | `false` | 是否输出灰度图 |
| O7 | `PreserveAspect` | `true` | FixedSize 时是否保持比例（边缘填充） |
| O8 | `BurnTimestamp` | `false` | 是否把录制时间戳烧印到图上（调试用，标注时建议关） |

### 3.6 抽帧 — 命名、组织与元数据（Naming）

| # | 参数 | 默认 | 说明 |
|---|---|---|---|
| N1 | `FilePattern` | `{session}_{index:D6}` | 支持 `{session}` `{index}` `{timestamp}` `{frame}` |
| N2 | `StartIndex` | `0` | 起始序号 |
| N3 | `SubFolderPerSession` | `true` | 每个会话一个子目录 |
| N4 | `ExportMeta` | `true` | 生成 `frames.csv` + `meta.json`（含量化参数快照、每张的清晰度/亮度/来源时间戳）**便于追溯与复现** |
| N5 | `CleanupTemp` | `true` | 结束后清理临时候选帧目录 |

### 3.7 抽帧 — 安全与效率（Guard）

| # | 参数 | 默认 | 说明 |
|---|---|---|---|
| G1 | `DryRunPreview` | 按钮动作 | **先预览**：系统会抽多少张、因模糊/过暗/重复各剔除多少，不落盘。避免误生成几万张 |
| G2 | `MaxOutputCount` | `2000` | 硬上限，超出中止并提示 |
| G3 | `WorkerThreads` | 自动（物理核数/2） | 并行打分线程数 |
| G4 | `ThumbnailPreview` | `true` | 抽完后左侧显示缩略图网格，可手动删差图 |

### 3.8 自动预标注参数（AutoLabel，★Sir 已确认纳入本次）

> 价值：抽完帧直接产出**可训练的数据集**，人工只做修正而非从零标注。

| # | 参数 | 默认 | 说明 |
|---|---|---|---|
| A1 | `EnableAutoLabel` | `true` | 总开关 |
| A2 | `LabelModelPath` | `跟随当前已加载模型` | 也可指定 `yolo_models/*.onnx` |
| A3 | `ConfThreshold` | `0.25` | 推理置信度阈值 |
| A4 | `IouThreshold` | `0.45` | NMS IoU 阈值 |
| A5 | `LabelFormat` | `YOLO txt` | 每张图同名 `.txt`：`class cx cy w h`（归一化） |
| A6 | `ExportClassesFile` | `true` | 导出 `classes.txt`（类名顺序需与模型一致，由 ModelManager 提供） |
| A7 | `KeepNegativeFrames` | `true` | **是否保留无检出目标的图**（负样本）。训练通常需要，默认保留 |
| A8 | `MinInstances` | `0` | 低于此目标数的帧是否剔除（如只想留"至少有 1 个目标"的图，设 1） |
| A9 | `MaxInstances` | `0`(不限) | 剔除目标过多（画面杂乱）的帧 |

**实现方式**：复用现有 `IDetectionService` / `YoloDetectionService` 对落盘后的图片逐个推理，结果转 YOLO 归一化格式写 `.txt`。类名顺序以加载模型自带的名称为准（避免手写 classes 与模型错位）。

## 四、典型 ffmpeg 命令（本次会用到的）

```bash
# ① 录像：rawvideo 通过 stdin 灌入
ffmpeg -y -f rawvideo -pix_fmt bgr24 -s 3072x2048 -r 15 -i -
       -c:v libx264 -preset veryfast -crf 18 -pix_fmt yuv420p session.mp4

# ②a 抽帧：目标帧率 2fps
ffmpeg -i session.mp4 -vf fps=2 -q:v 2 tmp/%08d.jpg

# ②b 抽帧：均匀抽 N 张（先 ffprobe 取总帧数算出 step）
ffmpeg -i session.mp4 -vf "select='not(mod(n\,STEP))'" -vsync vfr -q:v 2 tmp/%08d.jpg

# ②c 抽帧：场景切换
ffmpeg -i session.mp4 -vf "select='gt(scene,0.3)'" -vsync vfr -q:v 2 tmp/%08d.jpg

# ffprobe 取元数据（时长/帧率/总帧数）
ffprobe -v error -select_streams v:0 -show_entries stream=nb_frames,r_frame_rate -of json session.mp4
```

## 九、风险与对策

| 风险 | 对策 |
|---|---|
| ffmpeg.exe 缺失/被杀软拦截 | `FfmpegLocator` 多路径探查 + 启动前可用性校验，失败时给出明确提示而非静默失败 |
| 相机帧率 > 写盘能力导致内存堆积 | **有界队列**（默认 60 帧）+ 满则丢最新帧策略，内存恒定 |
| 高分辨率（如 3072×2048）写 RawVideo 带宽大 | 提供 `RecordFps` 上限 + CRF 调节；必要时先缩放再编码（`RecordScale`） |
| 抽帧数量失控生成几万张 | DryRun 预览先行 + `MaxOutputCount` 硬上限 |
| 自动预标注类名与模型错位 | 类名**从加载的模型读取**，不写死；`classes.txt` 一并导出保证对齐 |
| 相机输出 Mono8 | 按 `Channels/IsColor` 自动选 `-pix_fmt gray / bgr24` |

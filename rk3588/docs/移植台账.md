## 三、SOP 引擎移植重点（易错清单）

从 Windows 版踩过的坑，移植时必须主动防范：

| # | 坑 | 移植时的动作 |
|---|---|---|
| 1 | **稳定帧门控误清零** | `ApplyStableFrameGate` 只对 `step.StepId == currentStepId` 生效；跳步探测每帧复用同一评估器实例，不区分会互踩（症状：步骤卡死+跳步不报警） |
| 2 | 门控跳过清单 | `HandStable`/`ObjectStable`（自管理帧数）、`HandMoveFromTo`（瞬时交互，真窗口仅数帧）、`TimeElapsed`/`SequenceComplete` |
| 3 | `ResetStableCounts()` | 挂在状态机 `Start()` / `Reset()` |
| 4 | 共享状态改动前排查全部调用方 | `ViolationDetector.DetectSkipStep` 是探测性调用，历史上曾漏 |
| 5 | YAML 解析器容忍未知字段 | C# 版 `ParseYaml` 曾因缺 `IgnoreUnmatchedProperties` 导致 5 个旧配方全加载失败 |
| 6 | 序列化/反序列化命名约定一致 | 靠 `[YamlMember(Alias="snake_case")]`，C++ 侧 yaml-cpp 需显式指定 key |
| 7 | 一步一检测 + AND 短路 | 不可表达"依次做 N 个动作"，重复工序必须拆多步（与 Windows 版一致） |
